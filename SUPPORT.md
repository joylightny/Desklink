# DeskBlink Support

## Contact

- Email: [joylightny@gmail.com](mailto:joylightny@gmail.com)
- Bug reports and feature requests: [GitHub Issues](https://github.com/joylightny/Desklink/issues)

## Information to include

For faster troubleshooting, include the DeskBlink version, macOS version, Mac model, Apple silicon or Intel, number of displays, trigger used, and clear reproduction steps.

Screenshots are helpful, but remove private information before attaching them. Never publish a complete DeskBlink license key in a GitHub issue.

## License help

For license activation, deactivation, refund, or purchase-email questions, contact the support email and include the email address used at checkout. Do not include payment-card details.

DeskBlink aims to respond within three business days. This is a response target, not a guaranteed service-level agreement.
